Parametric Curve Sketching

A complete FP1 worked example: key points, monotonicity, self-intersection and the final sketch.

x = t2 - 3,   y = t3 - 3t -∞ < t < +∞

1. Analyse before drawing

Symmetry

x(-t) = x(t),   y(-t) = -y(t)

The curve is symmetric about the x-axis.

Derivatives

dx/dt = 2t,   dy/dt = 3(t2 - 1)

dy/dx = 3(t2 - 1)/(2t),   t ≠ 0

Critical parameter values

t = -1, 1: horizontal tangents.

t = 0: vertical tangent.

The two derivatives are never zero together, so the curve is regular.

Self-intersection

x = 0 ⇒ t = ±√3,   y = 0

The curve crosses itself at (0, 0).

Slopes: -√3 and +√3
