Binomial → Poisson limit

Xₙ ~ Bin(n, λ/n),   λ fixed

Example: calls received by a company.

A company receives an average of 3 calls per hour; this is an average, not a maximum, so an hour may contain more than three calls. Divide the hour into n small slots. In the Binomial model, each slot is one trial—either a call occurs or it does not—with p = λ/n. The hourly count is Bin(n, λ/n), which approaches Poisson(λ) as n increases.
